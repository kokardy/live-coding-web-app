## 今日やること / ゴール

- Docker Compose で以下を立ち上げる
  - backend (FastAPI)
  - PostgreSQL (DB)
  - Redis (キャッシュ)
- ゴール
  - `docker compose up` で 3 つのコンテナが起動する
  - backend コンテナから DB / Redis に接続できる状態になる

---------

## 前提 / 対象

- 前提
  - Docker / Docker Compose がインストール済み
  - git が使える環境（Linux / macOS / WSL など）
- 対象(強いて言えば)
  - Docker Composeでローカル開発環境を整えたい人

---------

## ファイル構成

- `docker-compose.yaml`
  - backend / postgresql / redis をまとめて起動する
- `backend/`
  - FastAPI を動かすアプリケーションコード
  - Dockerfile, uv プロジェクト など
- `postgresql/docker-entrypoint-initdb.d/001-init-db.sh`
  - アプリ用データベースとユーザーを作成
- `redis/.gitignore`
  - 空ディレクトリを git 管理するためのプレースホルダー

（`frontend/` は将来追加予定、今回は触らない）

---------

## docker-compose.yaml 全体像

- services
  - `backend`
  - `postgresql`
  - `redis`

- 設定ファイル
  - `.env.local`
    - DB 名, ユーザー名, パスワード などの環境変数を定義

- 個人設定（任意）
  - `docker-compose.override.yaml`
    - 開発者ごとにポート番号やボリュームを上書き
    - リポジトリには含めず、`.git/info/exclude` で除外

---------

## postgresql

- `docker-entrypoint-initdb.d/`
  - コンテナ初回起動時に実行されるスクリプトを配置
- `001-init-db.sh`
  - アプリ用 DB `APP_DB_NAME` を作成
  - アプリ用ユーザー `APP_DB_USER` を作成
  - ローカル開発向けのシンプルな設定にする

※ 本番では別のセキュリティ設定にする想定

---------

## backend プロジェクト作成 (uv)

- `uv init` でプロジェクト初期化
- `uv pin python 3.12`
  - 3.12 系を前提として開発する
- `uv add`
  - `fastapi`
  - `pydantic`
  - `psycopg[binary]`
  - `alembic`
  - `httpx`
  - `sqlalchemy`
  - `uvicorn`

※ 今回は「起動するところまで」。今後の配信で API 実装やマイグレーションを追加予定。

---------

## backend 開発ツール (uv add -D)

- `pytest-asyncio`
- `pytest-cov`
- `pytest-mock`
- `ruff`
- `lefthook`

※ 最低限のテスト・Lint 環境だけ入れておき、
　必要に応じて `pytest-html` などは後から追加する方針。

---------

## backend の Dockerfile

- ベースイメージ
  - `python:3.12-slim`
  - イメージサイズを抑えつつ、必要なライブラリを追加
  - ステージングビルドはした方がいいけど、今回はシンプルに1段階で構築
- ポイント
  - `uv` を使って依存関係を解決
  - `non-root` ユーザーでアプリを実行
  - `uvicorn` で FastAPI アプリを起動

---------

## docker composeで起動

- `docker compose up -d`
- `docker compose logs`
