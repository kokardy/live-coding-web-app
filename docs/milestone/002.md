## Alembic セットアップ

- `uv run alembic init` で初期化
- `uv run alembic.ini` と `env.py` の修正
  - SQLAlchemy の `Base.metadata` を読み込ませる
    `from src.app.infrastructure.models import Base`
    `target_metadata = Base.metadata`
  - 環境変数からDB接続URL（PostgreSQL）を取得するように設定
  - `sqlalchemy.url = postgresql+psycopg://postgres:password@localhost/app`
- 初回のマイグレーションファイルを作成
  - `uv run alembic revision --autogenerate -m "init tables"`
- マイグレーションの実行
  - `uv run alembic upgrade head`
